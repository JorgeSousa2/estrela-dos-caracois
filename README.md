
# Estrela dos Caracóis

Website desenvolvido para o restaurante Estrela dos Caracóis.

## Sobre o projeto

Página web responsiva que apresenta as especialidades do restaurante, informações sobre o espaço, novidades e contactos.

## Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox e CSS Grid
- Git e GitHub

## Funcionalidades

- Menu de especialidades com imagens
- Apresentação do restaurante
- Secção de novidades
- Formulário de contacto
- Design adaptado a dispositivos móveis

## Autor
Jorge Sousa


## Como visualizar o projeto

1. Faça o download do repositório através da opção "Code" > "Download ZIP" no GitHub.
2. Extraia os ficheiros para uma pasta no computador.
3. Abra o ficheiro `index.html` num navegador, como Google Chrome, Firefox ou Microsoft Edge.

O projeto foi desenvolvido em HTML e CSS, não sendo necessária a instalação de dependências.
